## 💻 Sobre o Projeto

O **EstoDoList** é um projeto de lista de tarefas (*To-Do List*) desenvolvido com o objetivo principal de **praticar e aprimorar as habilidades de desenvolvimento front-end**. Ele oferece uma interface limpa e responsiva, permitindo aos usuários gerenciar suas tarefas diárias de forma simples e intuitiva.

Toda a persistência de dados é feita localmente no navegador, utilizando o **`localStorage`** para garantir que as tarefas não se percam ao recarregar a página.

## ✨ Funcionalidades

O EstoDoList foi construído com as seguintes capacidades essenciais para a gestão de tarefas:

  * **Adicionar Tarefa:** Crie novas tarefas rapidamente com a descrição.
  * **Excluir Tarefa:** Remova permanentemente tarefas que não são mais necessárias.
  * **Marcar como Concluída:** Alterne o status da tarefa para "concluída" ou "pendente".
  * **Pesquisar Tarefa:** Encontre tarefas específicas através de uma barra de pesquisa.
  * **Filtrar Tarefas:** Visualize apenas tarefas *pendentes*, *concluídas* ou *todas* as tarefas.

## 🛠️ Tecnologias

Este projeto é um excelente exemplo de como criar uma aplicação front-end robusta e moderna utilizando uma pilha de tecnologias leve e eficiente:

  * **HTML5:** Estrutura básica e semântica do projeto.
  * **Tailwind CSS:** Framework CSS *utility-first* para um design rápido, responsivo e altamente personalizável.
  * **JavaScript (Vanilla JS):** Lógica principal da aplicação, manipulação do DOM e gestão das funcionalidades.
  * **`localStorage`:** Utilizado para a persistência das tarefas no lado do cliente.
